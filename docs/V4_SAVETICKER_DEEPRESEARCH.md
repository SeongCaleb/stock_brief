# Stock Brief V4.2 — 세이브티커 우선 뉴스 및 투자 가설 강화

## 우선 출처
- 세이브티커 https://saveticker.com/news 는 사용자가 선호하는 **우선 뉴스 발굴원**으로 배치했습니다.
- 공개 목록은 JavaScript 페이지이므로 정적 기사 링크가 없을 수 있습니다. 날짜가 확인되지 않은 목록 링크는 '아이디어'로만 취급합니다.
- 공개 사이트 제한 시 Google News의 `site:saveticker.com/news when:2d` 발행시각 있는 검색 RSS를 보조로 시도합니다. 이 경우 Google News 링크를 원문으로 직접 주장하지 않습니다.
- 실제 피드/기사 확인 불가 시 이메일에 '수집 불가/0건'을 그대로 표기합니다. 무조건 SAVE 뉴스가 있다고 가정하지 않습니다.
- SAVE가 1차 자료인 것은 아닙니다. Reuters·보도자료·기업 공시 등 원출처가 확인되면 원출처와 구분하여 해석합니다.

## 기업별 AI 심층 분석
- 관심 기업 최대 3개를 하나의 Claude 요청으로 검토합니다.
- 단기 급등 예측이 아니라 3~6개월 성장 가설, 촉매, 반대 시나리오, 진입 조건, 가설 무효화, VOO 등 대체안 비교를 작성합니다.
- 입력은 수집된 가격/재무 추정 및 최근 뉴스 제목에 제한됩니다. 검증되지 않은 사실이나 목표주가를 추정해서 만들지 않습니다.
- AI 연결 장애가 발생하면 기본 정량 분석으로 돌아갑니다. 새 분석이 없어도 매일 브리핑은 발송됩니다.

## 실제 수집 범위
- 세이브티커: 공개 뉴스 목록 + 일시가 확인되는 사이트 한정 검색 결과, 품질·접근 가능성은 매일 달라질 수 있습니다.
- 위폴: GitHub 실행 환경에서 최근 HTTP 429 차단이 확인되었습니다. 요청제한 우회 없음.
- 오선의 미국 증시 라이브: 공식 공개 영상 피드에서 제목·날짜 확인 가능. 영상 전체 자막은 아직 아님.
- 아카라이브 주식 채널: 접근 제한으로 본문 자동 수집 미연결.
