# Stock Brief V5: 의사결정형 브리핑

## 도입 범위
- **맨 위의 시장 국면**: VIX, 하이일드 스프레드, 10년 국채 수익률, SPY 200일선 차이를 활용하며 실제 시장 breadth는 측정하지 않습니다.
- **자산 배분**: 현금·초단기채, 미국 지수, 미국 외 주식, 개별 주식, 금 총 100%. 중립 예시 45/25/15/10/5에서 시작. 시장 정보 부족 시 이전 가정 유지. 하루 항목별 최대 5%p 변경. 사용자의 실제 위험 성향이 반영되지 않은 예시이며 거래 지시 아님.
- **투자 점수**: 성장(25), 밸류에이션(20), 재무건전성(20), 촉매(15), 추세(10), 위험 대비 보상(10). 미확인 항목은 0점이며 근거 신뢰도·가격 매력도는 별개 표시. 이 점수는 기대수익률이나 성공확률이 아닙니다.
- **행동**: 분할 매수 검토 / 조건부 진입 대기 / 대기 / 제외. 전체 시장 스트레스 및 데이터 부족 상태에서는 자동 매수 검토를 제한합니다.
- **가격 시나리오**: 현재 선행 EPS 추정을 기준으로 EPS 재추정과 P/E 재평가의 곱을 계산. 기본 0/0%, 상승 +10/+10%, 하락 -15/-15% (단순 민감도). 확률이나 실증적 목표가가 아닙니다. 피어 P/E에 따른 진입 감시구간은 참고치이며 비교기업 2곳 이상 없으면 표시하지 않습니다.
- **추천·보류 추적**: 각 실행에서 실제 관찰한 기업의 결정·점수·가격·VOO 가격을 전송 후 기록. 나중에 기준일 대비 가격 변동과 VOO 가격 초과수익, 샘플 관찰 최고/최저 변화, 결정 변경을 표시합니다. 전체 시장에 대한 성과 통계나 실제 보유 수익과 다릅니다.
- **우선 뉴스**: 세이브티커 뉴스 색인 피드 우선, 기존 RSS·오선·위폴 공개 목록 참고. 세이브티커 본문, 아카라이브 로그인 접근은 아직 미지원.
